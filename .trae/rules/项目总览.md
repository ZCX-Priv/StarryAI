# AIChat 项目总览

## 技术栈
- 框架：React 19 + TypeScript(严格模式) + Vite 8
- 状态管理：Zustand 5（9个Store：chat/agent/model/key/mode/stream/theme/ui/memory）
- 样式：TailwindCSS 4 + @tailwindcss/vite插件
- UI库：shadcn/ui(zinc主题+CSS变量) + lucide-react图标 + sonner提示 + clsx类名
- Markdown：react-markdown + rehype-highlight + remark-gfm
- 存储：IndexedDB(idb)
- 路径别名：@/* → ./src/*（vite.config.ts resolve.alias处理，tsconfig paths仅IDE提示）

## 编码规范
- 禁止使用any类型；组件Props必须定义接口；Store需State+Actions接口分离
- 核心类型定义在src/types/index.ts（Chat, Message, ModelInfo, AgentItem, ModeType等）
- ESLint检查：npm run lint
- 类型检查：npx tsc --noEmit

## 目录结构
- components/：agents(智能体)、chat(聊天)、layout(布局)、modals(弹窗)、ui
- hooks/：自定义Hook
- services/：API/存储/迁移；status/：Zustand Store
- render/：Markdown渲染+思考块
- prompts/：模式提示词
- context/：上下文管理
