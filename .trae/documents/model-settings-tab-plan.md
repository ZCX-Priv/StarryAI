# 模型设置标签页实现计划

## 需求概述
在设置模态框的"外观"和"密钥"标签页之间新增"模型"标签页，包含以下功能：
- 默认模型选择
- 温度（temperature）调节
- top_p 调节
- 上下文长度调节（0-25条）

## 实现步骤

### 1. 修改 `js/state.js`
- 添加新的状态变量：
  - `temperature`: 默认值 0.7
  - `topP`: 默认值 1.0
  - `contextLength`: 默认值 10（条消息）

### 2. 修改 `js/config.js`
- 在 `KEYS.KEYS_MAP` 中添加新的配置键：
  - `TEMPERATURE`: 'pollen_temperature'
  - `TOP_P`: 'pollen_top_p'
  - `CONTEXT_LENGTH`: 'pollen_context_length'

### 3. 修改 `js/app.js`
- 在初始化时加载新的配置项

### 4. 修改 `index.html`
- 在设置模态框的标签页区域添加"模型"标签按钮
- 调整标签页顺序为：外观 → 模型 → 密钥

### 5. 修改 `js/modals.js`
- 修改 `renderSettings()` 函数：
  - 添加 `model` 标签页的渲染逻辑
  - 从外观标签页移除默认模型选择，移到模型标签页
  - 添加温度、top_p、上下文长度的滑块控件
- 修改 `switchTab()` 函数，支持新的模型标签页

### 6. 修改 `js/keys.js`
- 添加保存模型参数的方法：
  - `setTemperature(value)`
  - `setTopP(value)`
  - `setContextLength(value)`

### 7. 修改 `js/api.js`
- 修改 `_params()` 方法，使用用户配置的 temperature 和 top_p 参数

### 8. 修改 `js/chat.js`
- 修改消息构建逻辑，根据 `contextLength` 限制发送的消息数量

### 9. 修改 `css/modals.css`
- 添加滑块（range input）样式
- 添加参数显示值的样式

## 文件修改清单

| 文件 | 修改内容 |
|------|----------|
| `js/state.js` | 添加 temperature, topP, contextLength 状态 |
| `js/config.js` | 添加配置键映射 |
| `js/app.js` | 加载新配置项 |
| `index.html` | 添加模型标签按钮 |
| `js/modals.js` | 添加模型标签页渲染 |
| `js/keys.js` | 添加参数设置方法 |
| `js/api.js` | 使用自定义参数 |

## 参数范围
- **温度 (temperature)**: 0.0 - 2.0，步进 0.1，默认 0.7
- **Top P**: 0.0 - 1.0，步进 0.05，默认 1.0
- **上下文长度**: 0 - 25 条，步进 1，默认 10 条
