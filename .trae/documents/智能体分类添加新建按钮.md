# 智能体分类添加"+"按钮功能实施计划

## 需求分析
在智能体分类标签栏的所有分类右侧添加一个"+"按钮,允许用户新建自定义分类。

## 当前代码结构
- **HTML**: `index.html` 第231-234行,包含 `agents-tabs-container` 容器
- **CSS**: `css/agents.css` 定义了 `.agents-tabs` 和 `.agent-tab` 样式
- **JavaScript**: `js/agents.js` 中的 `renderCategories()` 方法负责渲染分类标签

## 实施步骤

### 1. 修改 JavaScript 逻辑 (`js/agents.js`)

#### 1.1 修改 `renderCategories()` 方法
- 在渲染完所有分类标签后,添加一个"+"按钮
- 为"+"按钮添加特殊的样式类 `agent-tab-add`
- 添加点击事件处理

#### 1.2 添加新分类创建功能
- 创建 `openAddCategoryModal()` 方法:打开创建分类的模态框
- 创建 `createCategory()` 方法:处理新分类的创建逻辑
- 将新分类保存到 IndexedDB 中
- 更新 `config.categories` 数组
- 重新渲染分类标签

#### 1.3 添加分类数据管理
- 在 `loadCustomAgents()` 中同时加载自定义分类
- 在 `init()` 方法中初始化自定义分类

### 2. 添加 CSS 样式 (`css/agents.css`)

#### 2.1 为"+"按钮添加样式
- 创建 `.agent-tab-add` 类
- 设置圆形按钮样式
- 添加悬停效果
- 确保与现有标签样式协调

### 3. 修改 HTML 结构 (`index.html`)

#### 3.1 添加创建分类的模态框
- 创建一个新的模态框 `create-category-modal`
- 包含分类名称输入框
- 添加"取消"和"创建"按钮

### 4. 数据持久化

#### 4.1 使用 IndexedDB 存储自定义分类
- 在 `IDBStore` 中添加自定义分类的存储逻辑
- 页面加载时从 IndexedDB 读取自定义分类
- 创建新分类时保存到 IndexedDB

## 技术细节

### "+"按钮设计
- 使用圆形按钮,内部显示"+"符号
- 与现有标签按钮高度一致
- 点击时打开模态框输入分类名称

### 分类数据结构
```javascript
{
  id: 'custom_category_' + Date.now(),
  name: '用户输入的分类名称',
  isCustom: true
}
```

### 模态框设计
- 标题: "创建分类"
- 输入框: 分类名称 (最多10个字符)
- 按钮: "取消" 和 "创建"

## 文件修改清单
1. `js/agents.js` - 添加分类创建逻辑
2. `css/agents.css` - 添加"+"按钮样式
3. `index.html` - 添加创建分类模态框

## 测试要点
- 点击"+"按钮能正常打开模态框
- 输入分类名称后能成功创建
- 新创建的分类显示在标签栏中
- 刷新页面后自定义分类仍然存在
- 新分类可以正常筛选智能体
