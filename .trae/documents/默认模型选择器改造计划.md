# 将"默认模型"从列表改为选择器

## 任务概述
将设置页面中的"默认模型"选择方式从列表形式改为下拉选择器（select），提升用户体验和界面简洁性。

## 当前实现分析

### 现有代码位置
- **前端渲染**: `js/modals.js` 第35-41行
- **模型数据**: `js/config.js` 中的 `DEFAULT_MODELS` 数组
- **样式定义**: `css/modals.css` 中的 `.sec-row` 等样式

### 当前实现方式
```javascript
<div class="sec-title">默认模型</div>
<div class="sec-card">
  ${state.models.map(m=>`<div class="sec-row" style="cursor:pointer" onclick="Keys.setModel('${m.id}')">
    <div class="sec-row-label">${Renderer.escHtml(m.label||m.id)}</div>
    ${state.model===m.id?`<svg>...</svg>`:''}
  </div>`).join('')}
</div>
```

当前使用列表形式展示所有模型，每个模型占一行，点击选择。

## 实施计划

### 1. 修改 HTML 结构（js/modals.js）
**位置**: `js/modals.js` 第35-41行

**修改内容**:
- 将列表形式的 `sec-row` 改为下拉选择器 `<select>`
- 保持 `sec-card` 容器结构
- 添加选择器样式类名

**新代码结构**:
```javascript
<div class="sec-title">默认模型</div>
<div class="sec-card">
  <div class="sec-row">
    <select class="model-selector" onchange="Keys.setModel(this.value)">
      ${state.models.map(m=>`
        <option value="${m.id}" ${state.model===m.id?'selected':''}>
          ${Renderer.escHtml(m.label||m.id)}
        </option>
      `).join('')}
    </select>
  </div>
</div>
```
