# 修复模型选择器按钮显示问题

## 问题描述
模型选择器按钮（model-pill）显示的仍然是模型 ID（如 "openai"），而不是模型的别名（如 "gpt-5.4-nano"）。

## 问题分析

### 当前代码位置
- **文件**: `js/ui.js`
- **函数**: `UI.renderModelPill()` (第166-169行)

### 当前逻辑
```javascript
renderModelPill() {
  const lbl = document.getElementById('model-pill-label');
  if (lbl) lbl.textContent = state.model;
}
```

### 问题原因
函数直接显示 `state.model`，这是模型的 ID 字段（如 "openai"），而不是模型的 label 字段（如 "gpt-5.4-nano"）。

## 解决方案

### 修改 `UI.renderModelPill()` 函数
需要在 `state.models` 数组中查找当前模型，然后显示其 `label` 属性。

### 修改后的代码
```javascript
renderModelPill() {
  const lbl = document.getElementById('model-pill-label');
  if (lbl) {
    const currentModel = state.models.find(m => m.id === state.model);
    lbl.textContent = currentModel ? currentModel.label : state.model;
  }
}
```

## 注意事项

1. **容错处理**: 如果找不到对应模型，仍然显示 `state.model` 作为后备
2. **性能**: `find()` 方法性能良好，不会影响用户体验
3. **兼容性**: 修改后的代码与现有逻辑完全兼容
