# 智能体按钮改造与广场页面实现计划

## 📋 需求概述
将侧边栏的"智能体"从静态标签（`sb-section`）改为按钮样式（类似"新对话"按钮），点击后跳转到智能体广场页面，展示各种 AI 智能体卡片网格。

## 🎯 目标效果
参考用户提供的图片，实现：
- 按钮样式：带图标 + "智能体"文字，蓝色主题风格
- 点击后显示智能体广场：包含标签分类（工作、学习、创作、生活）、智能体卡片网格、使用统计等

#### 5.2 在 Agents 对象中添加广场渲染方法（agents.js）

```javascript
renderPlaza() {
  const grid = document.getElementById('agents-grid');
  if (!grid) return;

  // 示例数据（实际应从 API 或配置加载）
  const plazaAgents = [
    {
      id: 'writer-assistant',
      name: '全能写作助手',
      avatar: 'agents/writer.png',
      description: '提供多种文案创作选择，轻松完成各种文案任务。',
      usage: '1347.6万',
      author: '豆包官方',
      category: 'work'
    },
    {
      id: 'image-prompt',
      name: '识图生成提示词',
      avatar: 'agents/image.png',
      description: '上传图片，根据图片内容精准生成提示词，帮助...',
      usage: '106万',
      author: '豆包识图',
      category: 'create'
    },
    // ... 更多智能体
  ];

  grid.innerHTML = plazaAgents.map(agent => `
    <div class="agent-card" onclick="Agents.useAgent('${agent.id}')">
      <img src="image/${agent.avatar}" alt="${agent.name}" class="card-avatar"
           onerror="this.style.display='none'">
      <div class="card-content">
        <div class="card-name">${agent.name}</div>
        <div class="card-desc">${agent.description}</div>
        <div class="card-meta">
          <span>
            <svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2">
              <path d="M17 21v-2a4 4 0 0 0-4-4H5a4 4 0 0 0-4 4v2"/>
              <circle cx="9" cy="7" r="4"/>
            </svg>
            ${agent.usage}人聊过
          </span>
          <span>@${agent.author}</span>
        </div>
      </div>
    </div>
  `).join('');

  // 初始化标签切换
  this.initTabs();
},

initTabs() {
  document.querySelectorAll('.agent-tab').forEach(tab => {
    tab.addEventListener('click', (e) => {
      document.querySelectorAll('.agent-tab').forEach(t => t.classList.remove('active'));
      e.target.classList.add('active');
      // 根据分类过滤显示（可扩展）
    });
  });
},

useAgent(agentId) {
  this.select(agentId);
  UI.closeModal('agents-modal');
  UI.showToast(`已选择智能体`);
},
```

## ⚠️ 注意事项

1. **图标资源**：确保 SVG 图标清晰且语义正确（使用用户组图标代表"智能体广场"）
2. **性能考虑**：智能体卡片数量较多时需虚拟滚动或分页
3. **数据源**：当前方案使用硬编码示例数据，生产环境应接入 API
4. **无障碍访问**：按钮需添加适当的 aria-label 和键盘导航支持
