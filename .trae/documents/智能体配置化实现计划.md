# 智能体功能实现计划

## 目标
从 `agents.json` 加载智能体的分类和列表，实现真正的智能体功能，包括分类筛选和动态渲染。

## 当前状态分析

### 现有文件
- `config/agents.json` - 当前只有简单的智能体列表（3个智能体），无分类信息
- `js/agents.js` - 包含硬编码的 `plazaAgents` 数组（14个智能体），有category属性但未从配置加载
- `index.html` - 分类标签硬编码（工作、学习、创作、生活、我的）
- `css/agents.css` - 样式已完备

### 问题
1. 智能体数据硬编码在JS中，无法通过配置文件灵活管理
2. 分类标签硬编码在HTML中，无法动态扩展
3. 分类筛选功能未实现

---

### 步骤2: 修改 index.html

将硬编码的分类标签改为动态容器：

```html
<div class="agents-tabs-left" id="agents-tabs-container">
  <!-- 动态生成分类标签 -->

```

### 步骤3: 修改 agents.js

#### 3.1 更新 loadConfig 方法
确保正确加载新的JSON结构。

#### 3.2 新增 renderCategories 方法
从配置读取分类并动态生成标签按钮。

#### 3.3 重构 renderPlaza 方法
- 从 `this.config.agents` 读取智能体数据
- 移除硬编码的 `plazaAgents` 数组
- 实现分类筛选功能

#### 3.4 新增 filterByCategory 方法
根据选中的分类筛选显示智能体。

#### 3.5 更新 initTabs 方法
绑定分类切换事件，实现筛选逻辑。
