# 智能体功能实现计划

## 需求概述

在新建对话按钮下方添加"智能体"功能，允许用户选择不同的智能体进行对话。每个智能体有独立的名称、头像和系统提示词。

## 文件结构规划

```
AIChat/
├── image/                    (新建目录 - 统一存放所有图片资源)
│   ├── agents/               (智能体头像)
│   │   ├── assistant.png
│   │   ├── coder.png
│   │   └── writer.png
│   └── banner/               (banner图标)
│       ├── image.png
│       ├── solve.png
│       └── ...
├── config/
│   ├── banner.json           (修改 - 图标路径改为image/banner/)
│   └── agents.json           (新建 - 智能体配置)
├── prompts/
│   ├── agents/               (新建目录 - 智能体提示词)
│   │   ├── assistant.md
│   │   ├── coder.md
│   │   └── writer.md
│   └── ...
├── js/

```

## 实现步骤

### 步骤1: 创建图片资源目录结构

**目录**: `image/`

创建子目录：
- `image/agents/` - 存放智能体头像图片
- `image/banner/` - 存放banner图标图片

### 步骤2: 创建智能体配置文件

**文件**: `config/agents.json`

定义智能体列表，每个智能体包含：
- `id`: 唯一标识符
- `name`: 显示名称
- `avatar`: 头像图片路径（相对于image/目录）
- `prompt`: 对应的提示词文件名
- `description`: 简短描述

示例结构：
```json
{
  "agents": [
    {
      "id": "assistant",
      "name": "默认助手",
      "avatar": "agents/assistant.png",
      "prompt": "assistant.md",
      "description": "通用AI助手"
    },
    {
      "id": "coder",
      "name": "编程专家",
      "avatar": "agents/coder.png",
      "prompt": "coder.md",
      "description": "专注于编程问题"
    },
    {
      "id": "writer",
      "name": "写作助手",
      "avatar": "agents/writer.png",
      "prompt": "writer.md",
      "description": "擅长文案写作"
    }
  ]
}
```

### 步骤3: 创建智能体提示词目录和文件

**目录**: `prompts/agents/`

创建示例智能体提示词文件：
1. `assistant.md` - 默认助手提示词
2. `coder.md` - 编程专家提示词
3. `writer.md` - 写作助手提示词

### 步骤4: 创建智能体处理模块

**文件**: `js/agents.js`

功能包括：
- `Agents.loadConfig()` - 加载智能体配置
- `Agents.loadPrompt(promptFile)` - 加载智能体提示词
- `Agents.renderList()` - 渲染智能体列表UI
- `Agents.select(agentId)` - 选择智能体
- `Agents.getCurrent()` - 获取当前选中的智能体

### 步骤5: 修改状态管理

**文件**: `js/state.js`

添加智能体相关状态：
- `currentAgentId`: 当前选中的智能体ID
- `agentPrompt`: 当前智能体的提示词

### 步骤6: 修改HTML界面

**文件**: `index.html`

在侧边栏"新对话"按钮下方添加智能体选择区域：
- 添加智能体列表容器
- 添加智能体选择UI

### 步骤7: 添加CSS样式

**文件**: `css/sidebar.css`

添加智能体相关样式：
- 智能体列表样式
- 智能体选中状态
- 智能体头像样式

### 步骤8: 修改应用初始化

**文件**: `js/app.js`

在应用初始化时：
- 加载智能体配置
- 渲染智能体列表
- 设置默认智能体

### 步骤9: 修改对话创建逻辑

**文件**: `js/chat.js`

修改 `Chat.create()` 方法：
- 支持传入智能体参数
- 创建对话时关联智能体

### 步骤10: 修改提示词构建逻辑

**文件**: `js/prompts.js`

修改系统提示词构建：
- 支持智能体提示词
- 将智能体提示词与主提示词合并

### 步骤11: 更新banner配置（可选）

**文件**: `config/banner.json`

将banner图标路径改为使用 `image/banner/` 目录下的图片文件。

## 技术细节

### 图片资源管理

所有图片资源统一存放在 `image/` 目录：
- 智能体头像: `image/agents/`
- Banner图标: `image/banner/`
- 配置中使用相对路径引用，如 `agents/assistant.png`

### 智能体与对话的关联

每个对话对象将新增 `agentId` 字段，用于记录该对话使用的智能体：
```javascript
const chat = {
  id: '...',
  title: '新对话',
  messages: [],
  createdAt: Date.now(),
  model: state.model,
  agentId: state.currentAgentId  // 新增
};
```

### 提示词加载流程

1. 应用启动时加载主提示词和智能体配置
2. 用户选择智能体时加载对应提示词
3. 发送消息时，将智能体提示词作为系统消息的一部分

### UI设计

智能体列表位于侧边栏，采用简洁的列表形式：
- 显示智能体头像和名称
- 当前选中的智能体高亮显示
- 点击切换智能体

## 预期效果

1. 用户可以在侧边栏看到智能体列表
2. 点击智能体可切换当前智能体
3. 新建对话时使用当前选中的智能体
4. 不同智能体有不同的行为和响应风格
5. 所有图片资源统一管理在 `image/` 目录下
