# 优化用户消息折叠按钮质感

## Summary
将当前项目中用户消息的「展开内容」/「收起内容」按钮，替换为参考项目 `参考/StarryAI-Old` 中 `.msg-collapse-btn` 的样式与交互，做到质感一模一样。

## Current State Analysis
- **当前按钮样式**：`src/index.css` 第 150-151 行，`.msg-expand-btn` 为透明背景、无圆角、无图标、颜色 `--accent2`，文案为「展开内容」/「收起内容」。
- **参考按钮样式**：`参考/StarryAI-Old/css/chat.css` 第 76-84 行，`.msg-collapse-btn` 为胶囊形（`border-radius: 20px`）、半透明白色背景（`rgba(255,255,255,.12)`）、白色文字（`rgba(255,255,255,.8)`）、带有一个向下/向上的箭头 SVG 图标，文案为「查看全部」/「收起」，hover 时背景变亮（`rgba(255,255,255,.2)`）。亮色模式下背景为 `rgba(37,99,235,.12)`，文字为 `var(--accent)`。
- **参考交互逻辑**：`参考/StarryAI-Old/js/ui.js` 第 124-131 行，点击按钮时箭头 SVG 的 `polyline points` 在向下（展开）和向上（收起）之间切换。

## Proposed Changes

### 1. `src/components/chat/MessageBubble.tsx`
**What**：将展开/收起按钮替换为带箭头图标的胶囊按钮，文案改为「查看全部」/「收起」。
**Why**：与参考项目的交互和文案保持一致。
**How**：
- 按钮 class 改为 `msg-collapse-btn`。
- 按钮内部渲染一个箭头 SVG，根据 `expanded` 状态切换箭头方向：
  - 收起状态（`expanded === false`）：`points="6 9 12 15 18 9"`（向下箭头）
  - 展开状态（`expanded === true`）：`points="18 15 12 9 6 15"`（向上箭头）
- 文案同步切换为「查看全部」/「收起」。

### 2. `src/index.css`
**What**：用 `.msg-collapse-btn` 替换现有的 `.msg-expand-btn` 样式。
**Why**：复刻参考项目的视觉质感。
**How**：
- 删除现有的 `.msg-expand-btn` 和 `.msg-expand-btn:hover` 规则。
- 添加 `.msg-collapse-btn`：
  ```css
  .msg-collapse-btn {
    display: inline-flex; align-items: center; gap: 4px;
    margin-top: 6px; padding: 3px 10px;
    background: rgba(255,255,255,.12); border: none; border-radius: 20px;
    color: rgba(255,255,255,.8); font-size: 11.5px; font-family: var(--font);
    cursor: pointer; transition: background .15s;
  }
  .msg-collapse-btn:hover { background: rgba(255,255,255,.2); }
  .msg-collapse-btn svg { flex-shrink: 0; }
  ```
- 在亮色模式覆盖区（`[data-theme="light"]` 区域）添加：
  ```css
  [data-theme="light"] .msg-collapse-btn { background: rgba(37,99,235,.12); color: var(--accent); }
  [data-theme="light"] .msg-collapse-btn:hover { background: rgba(37,99,235,.2); }
  ```
  > 注：参考项目中没有定义 hover 的亮色模式覆盖，但按视觉一致性补充 `background: rgba(37,99,235,.2)` 使 hover 有反馈。

## Assumptions & Decisions
1. **保持行数折叠逻辑**：当前实现的「超过 3 行折叠」逻辑比参考项目的「超过 80 字符折叠」更合理，因此仅替换按钮样式和文案，不改变折叠触发条件与截断方式。
2. **按钮位置不变**：继续放在 `.msg-bubble` 内部文本下方。
3. **亮色模式 hover**：参考项目中未定义 `[data-theme="light"] .msg-collapse-btn:hover`，为确保交互完整性，补充一个同色系的加深背景。

## Verification Steps
1. 发送一条超过 3 行的用户消息，观察气泡底部是否出现胶囊形「查看全部」按钮，带向下箭头，背景为半透明白色。
2. 点击后按钮变为「收起」，箭头指向上方，消息完整展开。
3. 切换亮色模式，确认按钮背景变为浅蓝色半透明，文字为蓝色。
4. 运行 `npx tsc --noEmit` 和 `npm run lint` 确认无错误。
