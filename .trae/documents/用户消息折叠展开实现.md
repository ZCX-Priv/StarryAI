# 用户消息折叠/展开功能实现计划

## Summary

在当前项目的 `MessageBubble.tsx` 中为用户消息添加折叠/展开交互：当用户消息超过 3 行时，默认只显示前 3 行并截断，同时在气泡底部提供「展开内容」/「收起内容」按钮。样式参考 ChatGPT 风格的行数限制折叠交互。

## Current State Analysis

* **用户消息渲染**：`MessageBubble.tsx` 第 19\~30 行，用户消息直接以纯文本放入 `.msg-bubble`，无 Markdown 处理，无任何截断逻辑。

* **用户消息样式**：`index.css` 第 142\~148 行，`.msg-bubble` 定义了 `max-width: 86%`、`white-space: pre-wrap`、`line-height: 1.75` 等，但没有 `max-height` 或 `line-clamp` 限制。

* **原版参考**：经确认，`原版` 文件夹中不存在用户消息折叠/展开功能，因此本实现为新增功能，遵循当前项目已有的视觉风格（蓝色气泡、圆角、阴影等）。

## Proposed Changes

### 1. `src/components/chat/MessageBubble.tsx`

**What**：在用户消息分支引入折叠状态管理与行数溢出检测。
**Why**：组件层是实现交互的最佳位置，不会污染全局 Store 数据。
**How**：

* 引入 `useState` 和 `useRef`。

* 增加本地状态 `expanded`（是否展开）和 `needsCollapse`（是否内容超过 3 行）。

* 使用 `useEffect` 在 `content` 变化后测量 `.msg-bubble` 的实际高度：

  * 通过 `getComputedStyle` 获取 `lineHeight`（若返回 `'normal'`，则按 `fontSize * 1.75` 估算）。

  * 3 行理论高度 = `lineHeight * 3`。

  * 若 `scrollHeight > lineHeight * 3 + 1`（容错 1px），则设置 `needsCollapse = true`。

* 当 `needsCollapse && !expanded` 时，给用户消息的 `.msg-bubble` 添加 `collapsed` 类。

* 在 `.msg-bubble` 内部追加一个按钮：

  * 折叠状态显示「展开内容」

  * 展开状态显示「收起内容」

  * 点击切换 `expanded` 状态

* 按钮放在 `.msg-bubble` 内部 `content` 之后，以便气泡背景色自然包裹。

### 2. `src/index.css`

**What**：添加用户消息折叠相关的 CSS 类。
**Why**：控制折叠时的最大高度、过渡动画、展开按钮的样式。
**How**：

* 新增 `.msg-bubble.collapsed`：

  ```css
  .msg-bubble.collapsed {
    display: -webkit-box;
    -webkit-line-clamp: 3;
    -webkit-box-orient: vertical;
    overflow: hidden;
  }
  ```

  > 注：`-webkit-line-clamp: 3` 会在第 3 行末尾自动显示省略号（`…`），符合"超过 3 行截断"的视觉效果。

* 新增 `.msg-expand-btn`：

  * 定位在气泡内部文本下方（不使用 absolute，使用 flex/block 自然流）。

  * 字体大小 `12px`，颜色使用 `--accent2`（与项目强调色一致）。

  * 背景透明，无边框，有 hover 效果（颜色变亮或加下划线）。

  * `margin-top: 6px`，`padding: 2px 0`，`cursor: pointer`。

  * 使用 `display: inline-flex` 配合 `gap: 4px`，可放置一个小图标（可选，本项目可仅用文字）。

* 新增 `.msg-expand-btn:hover`：下划线或颜色变为 `--accent`。

* 无需添加底部渐变遮罩（因为 line-clamp 已自带截断效果，且用户明确要求"显示展开内容按钮"即可）。

## Assumptions & Decisions

1. **截断策略**：采用 `-webkit-line-clamp: 3`，因为它能精确限制 3 行，并在截断处自动显示省略号。这是实现"超过 3 行折叠"最可靠且性能最好的方式。
2. **按钮位置**：按钮放在 `.msg-bubble` 内部，位于文本内容之后。这样按钮始终处于蓝色气泡区域内，视觉统一。
3. **不需要渐变遮罩**：line-clamp 本身会在第 3 行末尾截断并显示 `…`，额外添加渐变遮罩反而可能遮挡文字或按钮，因此决定不加。
4. **检测时机**：在 `useEffect` 中检测，依赖 `[content]`。因为用户消息是预渲染好的文本，DOM 高度测量是同步且准确的。
5. **收起状态**：展开后允许再次点击「收起内容」恢复折叠状态，按钮文案同步切换。
6. **仅用户消息生效**：AI 消息（assistant）保持原样，不做折叠。

## Verification Steps

1. 发送一条超过 3 行的用户消息，观察是否只显示前 3 行并在末尾有省略号。
2. 确认气泡底部出现「展开内容」按钮，按钮颜色为 `--accent2`，hover 有反馈。
3. 点击「展开内容」后，消息完整显示，按钮变为「收起内容」。
4. 点击「收起内容」后，消息恢复为 3 行折叠状态。
5. 发送一条不超过 3 行的用户消息，确认不出现「展开内容」按钮，无截断效果。
6. 运行 `npx tsc --noEmit` 确保无类型错误。
7. 运行 `npm run lint` 确保无 lint 错误。
