# 修改模型选择器计划

## 任务目标
修改模型选择器，使其从 `https://gen.pollinations.ai/models` 获取模型列表，并显示模型别名的第一个作为显示名称，对应的模型 ID 为模型的 name 字段。

## 当前状态分析

### 现有代码位置
- **文件**: `js/keys.js`
- **函数**: `Keys._loadModels()` (第17-51行)

### 现有逻辑
1. 从 `${API_BASE}/v1/models` 端点获取模型列表
2. 过滤掉包含特定关键词的模型（flux, image, audio, video 等）
3. 映射数据：`id = m.id`, `label = m.id`
4. 更新 `state.models` 数组

### API 数据结构分析
从 `https://gen.pollinations.ai/models` 获取的数据格式：
```json
{
  "name": "openai",
  "aliases": ["gpt-5.4-nano", "gpt-5-mini"],
  "description": "GPT-5.4 Nano - Fast & Balanced",
  "input_modalities": ["text", "image"],
  "output_modalities": ["text"],
  ...
}
```

## 实施步骤

### 步骤 1: 修改 API 端点
- **位置**: `js/keys.js` 第20行
- **修改**: 将 `${API_BASE}/v1/models` 改为 `https://gen.pollinations.ai/models`
- **原因**: 使用新的 API 端点获取模型列表

### 步骤 2: 调整数据解析逻辑
- **位置**: `js/keys.js` 第21-37行
- **修改内容**:
  1. 移除 `data.data` 的嵌套访问（新 API 直接返回数组）
  2. 保留现有的过滤逻辑（排除图片、音频、视频等模型）
  3. 修改映射逻辑：
     - `id`: 使用 `m.name` 字段
     - `label`: 使用 `m.aliases[0]`（如果存在），否则使用 `m.name`
     - `pollen`: 从 `m.pricing` 中提取价格信息

### 步骤 3: 更新模型数据映射
- **位置**: `js/keys.js` 第29-37行
- **修改后的映射逻辑**:
```javascript
const models = data
  .filter(m => !exclKeywords.some(kw => m.name.toLowerCase().includes(kw)))
  .filter(m => m.aliases && m.aliases.length > 0) // 确保有别名
  .map(m => ({
    id: m.name,
    label: m.aliases[0],
    pollen: m.pricing ? parseFloat(m.pricing.completionTextTokens) : null
  }));
```

### 步骤 4: 更新默认模型选择逻辑
- **位置**: `js/keys.js` 第40-43行
- **保持不变**: 如果当前模型不在列表中，选择第一个模型

### 步骤 5: 测试验证
1. 启动本地服务器
2. 打开应用
3. 检查模型选择器是否正确显示别名
4. 验证模型切换功能是否正常
