# 公式和代码渲染优化计划

## 问题分析

### 1. 实时渲染问题
**当前状态：**
- 流式渲染时，公式在未闭合状态下显示为原始文本（如 `$E=mc^2`）
- 只有在 `finalizeRender` 时才调用 `FormulaRenderer.typeset` 进行 MathJax 渲染
- 用户在输入公式时无法看到实时渲染效果
- 代码块在流式渲染时没有语法高亮，只是简单的转义显示

**期望状态：**
- 公式应该实时渲染，即用户输入 `$E=mc^2$` 后立即看到渲染效果
- 代码块应该在流式渲染时也显示语法高亮
- 使用异步处理避免频繁渲染导致的性能问题

### 2. 公式块大小问题
**当前状态：**
- `.formula-display` 有 `margin: 16px 0` 和 `padding: 12px 16px`
- 有背景色 `rgba(59,130,246,.05)`
- 公式块看起来比正常文本大很多

**期望状态：**
- 公式块大小应与正常文本相当
- 减小 margin 和 padding
- 移除或淡化背景色

### 3. 代码块位置问题
**当前状态：**
- 代码块的 `div` 不在消息容器的顶部
- 可能存在布局问题导致代码块位置不正确

**期望状态：**
- 代码块应该在消息容器中正确显示
- 确保布局正确，没有多余的空间

### 4. 消息保存问题
**当前状态：**
- `Chat.addMsg` 保存的是原始文本 `content`
- 每次渲染消息时都会重新调用 `Renderer.parseMarkdown` 和 `FormulaRenderer.typeset`
- 这可能导致性能问题，且每次渲染都需要等待 MathJax 处理

**期望状态：**
- 保存渲染后的 HTML 内容
- 加载消息时直接显示已渲染的内容，无需重新处理

### 2. js/renderer.js 修改

**添加实时公式和代码渲染逻辑：**

```javascript
_renderMultiLine(text, lastNL, stable, live) {
  const completePart = text.slice(0, lastNL + 1);
  const incompletePart = text.slice(lastNL + 1);

  if (stable.dataset.key !== completePart) {
    stable.innerHTML = this.parseMarkdown(completePart, false);
    stable.dataset.key = completePart;
    
    // 实时渲染公式和代码
    this._scheduleRender(stable);
  }

  live.innerHTML = incompletePart ? `<p>${this.escHtml(incompletePart)}</p>` : '';
}

_scheduleRender(element) {
  if (this._renderTimer) {
    clearTimeout(this._renderTimer);
  }
  
  this._renderTimer = setTimeout(() => {
    // 渲染公式
    FormulaRenderer.typeset(element);
    
    // 渲染代码高亮
    this._highlightCodeBlocks(element);
    
    this._renderTimer = null;
  }, 100);
}

_highlightCodeBlocks(element) {
  if (typeof hljs === 'undefined') return;
  
  const codeBlocks = element.querySelectorAll('pre code:not(.hljs)');
  codeBlocks.forEach(block => {
    try {
      hljs.highlightElement(block);
    } catch (e) {
      console.warn('Code highlight error:', e);
    }
  });
}
```

### 3. js/render/code.js 修改

**优化代码块实时高亮：**

```javascript
renderStreamingCodeBlock(code, lang) {
  const langLabel = lang || '代码';
  
  // 在流式渲染时也进行语法高亮
  let highlighted;
  if (typeof hljs !== 'undefined' && lang && lang !== 'text') {
    try {
      highlighted = hljs.highlight(code, { language: lang }).value;
    } catch {
      highlighted = this.escHtml(code);
    }
  } else {
    highlighted = this.escHtml(code);
  }
  
  return `<div class="code-block-wrap"><div class="code-block-header"><span class="code-block-lang">${langLabel}</span></div><div class="code-block-body"><pre><code class="hljs language-${langLabel}">${highlighted}</code></pre></div></div>`;
}
```

addMsg(role, content) {
  const chat = Chat.getActive();
  if (!chat) return;
  
  // 渲染内容
  const rendered = role === 'assistant' ? Renderer.parseMarkdown(content) : Renderer.escHtml(content);

    const u = chat.messages[0]?.content || '';
    chat.title = u.slice(0, 42) + (u.length > 42 ? '…' : '');
  }
  
  Store.saveChats();
}

addBubble(role, content, rendered = null) {
  const c = document.getElementById('messages');
  c.querySelector('.empty-state')?.remove();
  const isAI = role === 'assistant';
  const row = document.createElement('div');
  row.className = `msg-row ${role}`;
  
  // 优先使用已渲染的内容
  let bubbleContent = rendered || (isAI ? Renderer.parseMarkdown(content) : Renderer.escHtml(content));
  
  let collapseHtml = '';
  if (!isAI && content.length > 80) {
    const prev = Renderer.escHtml(content.slice(0, 80));
    bubbleContent = `<span class="msg-text-full" style="display:none">${Renderer.escHtml(content)}</span><span class="msg-text-preview">${prev}…</span>`;
    collapseHtml = `<br><button class="msg-collapse-btn" onclick="UI.toggleMsgCollapse(this)"><svg width="10" height="10" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2.5" stroke-linecap="round" stroke-linejoin="round"><polyline points="6 9 12 15 18 9"/></svg> 查看全部</button>`;
  }
  
  if (isAI) {
    row.innerHTML = `<div class="ai-msg-content">${bubbleContent}</div>`;
  } else {
    row.innerHTML = `
      <div class="msg-bubble">${bubbleContent}${collapseHtml}</div>
      <div class="msg-avatar"><svg width="12" height="12" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="M20 21v-2a4 4 0 0 0-4-4H8a4 4 0 0 0-4 4v2"/><circle cx="12" cy="7" r="4"/></svg></div>`;
  }
  
  c.appendChild(row);
  
  // 如果是新渲染的内容，需要调用 MathJax
  if (isAI && !rendered) {
    FormulaRenderer.typeset(row.querySelector('.ai-msg-content'));
  }
  
  return row.querySelector(isAI ? '.ai-msg-content' : '.msg-bubble');
}

renderMessages() {
  const chat = Chat.getActive(), c = document.getElementById('messages');
  c.innerHTML = '';
  if (!chat || !chat.messages.length) {
    c.innerHTML = `<div class="empty-state"><div class="empty-icon"><img src="logo.png" alt="Logo"></div><h2>我能帮您什么？</h2><p>开始对话，模型会自动了解您。</p></div>`;
    return;
  }
  
  chat.messages.forEach((msg, i) => {
    UI.addBubble(msg.role, msg.content, msg.rendered);
    if (msg.role === 'assistant' && i === chat.messages.length - 1) {
      UI.addMessageActions(c.lastElementChild);
    }
  });
  
  UI.scrollToBottom(false);
}

### 5. js/render/formula.js 优化

**优化渲染性能：**

```javascript
async typeset(element) {
  if (!this._mathJaxReady) {
    this._mathJaxQueue.push(element);
    this.init();
    return;
  }

  if (this._pendingTypeset) {
    clearTimeout(this._pendingTypeset);
  }

  // 使用更短的延迟进行实时渲染
  this._pendingTypeset = setTimeout(async () => {
    await this._doTypeset(element);
    this._pendingTypeset = null;
  }, 50);  // 从 50ms 保持不变，但会在流式渲染中更频繁调用
}
```

## 总结

本计划通过以下五个主要改进来优化公式和代码渲染：

1. **实时渲染**：在流式渲染过程中实时渲染已闭合的公式和代码块，提升用户体验
2. **样式优化**：减小公式块和代码块的大小，使其与正常文本更协调
3. **代码高亮**：在流式渲染时也显示代码语法高亮，而不是等代码块完全写完
4. **位置优化**：确保代码块在消息容器中正确显示，没有多余的空间
5. **性能优化**：保存渲染后的内容，避免重复渲染，提升加载速度

这些改进将显著提升公式和代码渲染的用户体验和性能。
