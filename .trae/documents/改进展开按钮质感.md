# 改进用户消息展开/收起按钮质感

## Summary
将当前新增的 `.msg-expand-btn`（纯文字、无背景、下划线 hover）改造为参考原版 `.msg-action-btn` 的胶囊形、细边框、透明背景按钮样式，使其质感与项目整体设计保持一致。

## Current State Analysis
- **当前 `.msg-expand-btn` 样式**（`src/index.css` 第150-151行）：
  - `display: inline-flex; align-items: center; margin-top: 6px; padding: 2px 0;`
  - `background: none; border: none; color: var(--accent2); font-size: 12px;`
  - hover 仅为 `color: var(--accent); text-decoration: underline;`
  - 视觉表现过于简陋，像普通链接而非精致按钮。
- **原版参考样式**（`原版/css/chat.css` 第96-106行 `.msg-action-btn`）：
  - 胶囊形：`border-radius: 20px; border: 1px solid var(--border2);`
  - 背景透明，hover 浮现浅灰背景：`background: var(--bg3)`
  - 字体克制：`font-size: 11.5px; color: var(--text3);`
  - 小巧内边距：`padding: 4px 10px;`
  - 这是原版中与消息相关的最精致按钮样式。
- **环境差异**：原版 `.msg-action-btn` 位于 AI 消息下方的浅色背景区域，而 `.msg-expand-btn` 位于用户蓝色气泡（`--user-bubble: #2563eb`）内部，因此颜色变量需要针对蓝色背景做适配，不能直接套用 `var(--text3)`。

## Proposed Changes

### 1. `src/index.css`
**What**：重写 `.msg-expand-btn` 及其 hover 样式，参考原版 `.msg-action-btn` 的胶囊质感，但适配蓝色气泡背景。
**Why**：用户明确反馈当前按钮质感不如原版，需要与项目整体设计语言统一。
**How**：
- 将 `.msg-expand-btn` 改为胶囊按钮：
  ```css
  .msg-expand-btn {
    display: inline-flex;
    align-items: center;
    gap: 5px;
    margin-top: 6px;
    padding: 4px 10px;
    background: none;
    border: 1px solid rgba(255,255,255,0.25);
    border-radius: 20px;
    color: rgba(255,255,255,0.85);
    font-family: var(--font);
    font-size: 11.5px;
    cursor: pointer;
    transition: all .15s;
  }
  ```
  - `border` 使用 `rgba(255,255,255,0.25)`：在蓝色气泡上形成可见但不突兀的细白边。
  - `color` 使用 `rgba(255,255,255,0.85)`：接近白色但略透明，在蓝色背景上对比度足够且不生硬。
  - `gap: 5px` 和 `padding: 4px 10px`：与原版 `.msg-action-btn` 保持一致的比例。
- hover 效果改为：
  ```css
  .msg-expand-btn:hover {
    background: rgba(255,255,255,0.12);
    color: #fff;
    border-color: rgba(255,255,255,0.35);
  }
  ```
  - hover 时背景浮现
