# 改进「展开内容/收起内容」按钮质感

## Summary
将当前 `.msg-expand-btn` 的样式从蓝色下划线文字按钮，改为参考原版 `.msg-action-btn` 的胶囊形细边框按钮风格，提升视觉质感。

## Current State Analysis
- **当前 `.msg-expand-btn` 样式**（`src/index.css` 第150-151行）：无边框、无背景、蓝色文字（`--accent2`）、hover 时变色加下划线。视觉上像一个普通文字链接，质感单薄。
- **原版参考 `.msg-action-btn`**（`原版/css/chat.css` 第96-106行）：胶囊形（`border-radius: 20px`）、1px 细边框（`var(--border2)`）、透明背景、hover 时浮现浅灰背景（`var(--bg3)`）、文字颜色克制（`var(--text3)`）。这是原版中最精致的消息区域按钮风格。

## Proposed Changes

### `src/index.css`
**What**：重写 `.msg-expand-btn` 和 `.msg-expand-btn:hover` 的 CSS，并补充亮色模式覆盖。
**Why**：当前下划线文字按钮质感单薄，胶囊形边框按钮更符合原版精致风格。
**How**：
- 将 `.msg-expand-btn` 改为：
  ```css
  .msg-expand-btn {
    display: inline-flex; align-items: center; gap: 5px;
    margin-top: 6px; padding: 4px 10px;
    background: none; border: 1px solid var(--border2);
    border-radius: 20px; cursor: pointer;
    font-family: var(--font); font-size: 11.5px;
    color: var(--text3); transition: all .15s;
  }
  ```
- hover 状态改为：
  ```css
  .msg-expand-btn:hover {
    background: var(--bg3); color: var(--text); border-color: var(--border2);
  }
  ```
- 添加亮色模式覆盖（放在 index.css 现有的 `[data-theme="light"]` 区域即可）：
  ```css
  [data-theme="light"] .msg-expand-btn { border-color: rgba(0,0,0,.18); color: var(--text2); }
  [data-theme="light"] .msg-expand-btn:hover { background: var(--bg4); color: var(--text); }
  ```

## Assumptions & Decisions
1. 直接复刻原版 `.msg-action-btn` 的全部尺寸和颜色参数（padding、border-radius、font-size、color、border、transition），因为这些参数已经过原版验证，视觉比例协调。
2. 保留 `margin-top: 6px` 以维持按钮与上方文本的间距。
3. 不需要修改 `MessageBubble.tsx`，仅修改 CSS 即可。

## Verification Steps
1. 发送超过 3 行的用户消息，观察「展开内容」按钮是否变为胶囊形细边框样式。
2. hover 按钮时，确认背景浮现浅灰色、文字变白（深色模式）。
3. 切换到亮色模式，确认边框和文字颜色正确适配。
4. 运行 `npx tsc --noEmit` 和 `npm run lint` 验证无错误。
